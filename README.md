 # かんたん家計簿アプリ
 
 ブラウザで動作するシンプルな家計簿アプリです。
 
 ## 機能
 - 収入/支出の追加
+- 種類に応じたカテゴリ選択
+  - 支出: 日常費、趣味レジャー費、雑費・予備費、家賃・マイホーム費、貯蓄、NISA、iDeCo
+  - 収入: 定期収入、臨時収入
 - 月フィルターで取引を絞り込み
 - 今月の収入・支出・収支のサマリー表示
 - 取引の個別削除/全削除
 - データを `localStorage` に保存
 
 ## 使い方
 1. `index.html` をブラウザで開く
 2. 日付・種類・カテゴリ・金額を入力して追加
 3. 月フィルターで表示を切り替え
 
 ## 補足
 - データはブラウザ内にのみ保存されます
 - 別ブラウザやシークレットモードではデータ共有されません
